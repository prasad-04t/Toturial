##  Variables
### What is a Variable?
A **variable** is simply a **named container used to store data** in memory.
Think of it like a labeled box:
* Label = variable name
* Content = value
Example:
* `age = 25` → “age” is the label, `25` is the value
  
### Why Variables Are Important

* Store data
* Reuse values
* Make programs dynamic
* Required in every programming language

### Syntax + Examples (Python vs Java vs JavaScript)

#### Basic Variable Declaration

| Concept        | Python   | Java          | JavaScript    |
| -------------- | -------- | ------------- | ------------- |
| Syntax         | `x = 10` | `int x = 10;` | `let x = 10;` |
| Type Required? | No       | Yes           | No            |
| End with `;`   | No       | Yes           | Yes           |
| Dynamic Typing | Yes      | No            | Yes           |
* **Python** → Simple and flexible: no type declaration, no semicolon, dynamically typed
* **Java** → Strict and explicit: must declare type, uses semicolon, statically typed
* **JavaScript** → Flexible like Python: no type required, uses semicolon, dynamically typed
### Examples Comparison

| Scenario | Python         | Java                   | JavaScript          |
| -------- | -------------- | ---------------------- | ------------------- |
| Integer  | `x = 10`       | `int x = 10;`          | `let x = 10;`       |
| Float    | `y = 10.5`     | `double y = 10.5;`     | `let y = 10.5;`     |
| String   | `name = "Sam"` | `String name = "Sam";` | `let name = "Sam";` |
| Boolean  | `flag = True`  | `boolean flag = true;` | `let flag = true;`  |


### Printing Variables

| Language   | Example                  |
| ---------- | ------------------------ |
| Python     | `print(x)`               |
| Java       | `System.out.println(x);` |
| JavaScript | `console.log(x);`        |

### Reassigning Variables

| Python              | Java                   | JavaScript            |
| ------------------- | ---------------------- | --------------------- |
| `x = 10` → `x = 20` | Allowed only same type | `let x = 10 → x = 20` |

* **Python** → Fully flexible: you can change both **value and type** anytime (`x = 10` → `x = "hello"`)
* **Java** → Restricted: you can change the **value**, but **type must stay the same**
* **JavaScript** → Flexible (with `let`): you can change the **value and even type**

# Key Differences (Important for Interviews)

| Feature       | Python      | Java    | JavaScript |
| ------------- | ----------- | ------- | ---------- |
| Typing        | Dynamic     | Static  | Dynamic    |
| Easy to write | Very easy   | Verbose | Easy       |
| Type safety   | Less strict | Strong  | Medium     |

### Real Example (All 3 Languages)

#### Python

```python
name = "Sam"
age = 25
salary = 50000.5

print(name)
print(age)
print(salary)
```
#### Java

```java
public class Main {
    public static void main(String[] args) {
        String name = "Sam";
        int age = 25;
        double salary = 50000.5;

        System.out.println(name);
        System.out.println(age);
        System.out.println(salary);
    }
}
```

---

#### JavaScript

```javascript
let name = "Sam";
let age = 25;
let salary = 50000.5;

console.log(name);
console.log(age);
console.log(salary);
```

#### Important Points

* **Python & JavaScript** → Dynamically typed - Variable type can **change at runtime**
* **Java** → Statically typed- Variable type is **fixed once declared**
* Use:
  * `type()` in Python
  * `typeof` in JavaScript

Python & JavaScript allow **type switching**, but Java strictly **prevents it**.

### Interview Tips (Important)
#### 1. What is a Variable?
A variable is a named memory location used to store data, and its value can be changed during program execution.
#### 2. Difference Between Static vs Dynamic Typing

| Static Typing                      | Dynamic Typing               |
| ---------------------------------- | ---------------------------- |
| Type is defined at compile time    | Type is decided at runtime   |
| Requires explicit type declaration | No need to declare type      |
| Errors are caught early            | Errors are caught at runtime |
| Example: Java                      | Example: Python, JavaScript  |

Static typing checks types at compile time, while dynamic typing determines types at runtime.

#### 3. Java Trick Question: Why Do We Declare Type?
In Java, we declare variable types to ensure:
* Type safety (avoid invalid operations)
* Efficient memory allocation
* Better performance during compilation

### 4. JavaScript Trick: Difference Between `var`, `let`, `const`

| Feature    | var      | let                       | const                     |
| ---------- | -------- | ------------------------- | ------------------------- |
| Scope      | Function | Block                     | Block                     |
| Re-declare | Yes      | No                        | No                        |
| Re-assign  | Yes      | Yes                       | No                        |
| Hoisting   | Yes      | Yes (but not initialized) | Yes (but not initialized) |

`var` is function-scoped and can be redeclared, `let` is block-scoped and can be reassigned, and `const` is block-scoped but cannot be reassigned.


#### 5. Python Question: Why No Type Declaration?
Python does not require type declaration because it is dynamically typed, meaning the type of a variable is automatically determined at runtime.
